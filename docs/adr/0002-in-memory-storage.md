# ADR-0002: In-memory хранилище для ПР14

- Статус: принято для ПР14
- Дата: 2026-11-27

## Контекст

Walking skeleton должен демонстрировать создание/чтение плана и проверку владельца без ранней привязки к файловой БД.

## Решение

Использовать `InMemoryPlanRepository` с минимальным контрактом `save` / `get_for_owner`. Экземпляр создаётся на приложение и может быть заменён в тестах.

## Последствия

- Нет настройки БД; каждый перезапуск очищает планы.
- Это только учебное хранилище: не подходит для нескольких worker-процессов или production.
- SQLite/дисковая реализация и миграция контрактных тестов остаются на последующие этапы.
