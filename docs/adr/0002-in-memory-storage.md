# ADR-0002: Сховище в пам’яті для ПР14

- Статус: прийнято для ПР14
- Дата: 2026-11-27

## Контекст

Walking skeleton має демонструвати створення й читання плану та перевірку власника без передчасної прив’язки до файлової бази даних.

## Рішення

Використовувати `InMemoryPlanRepository` із мінімальним контрактом `save` / `get_for_owner`. Екземпляр створюється для застосунку й може бути замінений у тестах.

## Наслідки

- Не потрібно налаштовувати базу даних; після кожного перезапуску плани очищуються.
- Це лише навчальне сховище: воно не підходить для кількох worker-процесів або production.
- Реалізація на SQLite/диску й перенесення контрактних тестів залишаються на наступні етапи.
