# ADR-0003: Контракт провайдера и mock по умолчанию

- Статус: принято для ПР14
- Дата: 2026-11-27

## Контекст

Тесты и демонстрации должны работать без сети, API-ключа и платного запроса.

## Решение

Прикладной сервис зависит от `PlanProvider` Protocol. Единственная доступная конфигурация ПР14 — `mock`; он детерминирован и поддерживает контролируемые режимы задержки, timeout, 429, unavailable, invalid JSON и обрыва потока. Контроллер и сервис не импортируют SDK.

## Последствия

- Повторяемые тесты без внешних систем и секретов.
- Реальный провайдер и gateway добавляются позже за отдельными абстракциями.
- Ошибки mock отображаются через единый закрытый каталог.
