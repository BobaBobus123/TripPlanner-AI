# ADR-0003: Контракт провайдера й mock за замовчуванням

- Статус: прийнято
- Дата: 2026-11-27

## Контекст

Тести й демонстрації мають працювати без мережі, API-ключа та платних запитів.

## Рішення

Оркестратор залежить від протоколу `PlanProvider`. Для локальних тестів і демонстрації за замовчуванням використовується детермінований `mock`; окремо доступні OpenAI-сумісний і recorded-провайдери. Mock підтримує керовані режими затримки, тайм-ауту, 429, недоступності, некоректного JSON і переривання. Контролер не імпортує SDK.

## Наслідки

- Відтворювані тести без зовнішніх систем і секретів.
- Реальний провайдер потребує серверного секрету та актуального налаштування вартості.
- Помилки mock відображаються через єдиний закритий каталог.
