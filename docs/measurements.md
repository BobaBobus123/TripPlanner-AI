Для живого замера выполнить 10+ запросов на фиксированных кейсах и записать выбранную модель, endpoint-тип (без URL с секретами), timestamp, задержку, usage-токены и стоимость по фактическому прайсу. Не сохранять API-ключ, сырой prompt или пользовательские данные. TTFT измеряется только при появлении настоящего stream-контракта.

Цены задаются `INPUT_COST_PER_MILLION_TOKENS` и `OUTPUT_COST_PER_MILLION_TOKENS` в USD/миллион токенов. Перед каждым запросом бюджетный guard резервирует консервативную оценку по prompt length и `MAX_OUTPUT_TOKENS`; фактическая сумма логируется для последующего сравнения. Прайс необходимо обновлять вручную по выбранному провайдеру.
